# Changelog

## 0.1.1

- Workspaces in the sidebar can be reordered: drag one, or use Move up and Move down. Adari keeps the order for each machine.
- Notifications when an agent needs you: a banner, a Dock badge and a menu bar item. Adari stays open when its window is closed.
- The first message in a new chat shows once and is no longer marked "Not sent" when it went.
- Report a Problem and Send Feedback, in the Help menu and in Settings › About. Each opens a filled-in GitHub issue in your browser. Nothing is sent until you submit it.

If no banner shows, allow Adari in System Settings › Notifications.
