# Changelog

## 0.1.2

- Antigravity CLI, Google's coding agent that runs Gemini 4 Neon, now has full Chat: its conversation as messages, with tool calls and their results. Its questions arrive as cards you answer with a click (trust this folder, run this command, create this file, accept this edit).
- New agent offers Model and effort for Antigravity CLI, Gemini 4 Neon first with its levels Low, Medium, High and Extra high.
- Chips under the message box show and change Antigravity CLI's model, level and mode (Supervised, Accept edits, Auto, Plan) while it runs. On a Mac reached over SSH, the list is the one Adari knows and Adari says so.
- In Plan mode, Codex's question and "Implement this plan?" arrive as cards. A question Claude Code asks with choices is also a card in Chat, including for a session that has a name.
- A card's answer still goes through after the pane is resized.
- New agent shows the new pane as soon as it exists and names a step that is slow.
- Before starting an agent, New agent installs or updates the Herdr integration it needs for Chat and says so in one line. A switch in Settings turns this off.
- Settings can update all of Herdr's integrations in one click and run an update command you set for each agent CLI.
- Sending a message with a picture to Claude Code empties the message box at once. It is confirmed from Claude Code's own record, so one that went is no longer put back in the box.
- In the Terminal view, clicks and drags reach a program that asks for the mouse. Hold Shift to select text with Adari instead.
- When macOS does not show Adari's notifications, Settings says so.

Codex's command question can still come back "Not sent" after a resize when the pane is narrow.

## 0.1.1

- Workspaces in the sidebar can be reordered: drag one, or use Move up and Move down. Adari keeps the order for each machine.
- Notifications when an agent needs you: a banner, a Dock badge and a menu bar item. Adari stays open when its window is closed.
- The first message in a new chat shows once and is no longer marked "Not sent" when it went.
- Report a Problem and Send Feedback, in the Help menu and in Settings › About. Each opens a filled-in GitHub issue in your browser. Nothing is sent until you submit it.

If no banner shows, allow Adari in System Settings › Notifications.
